LAB 10: Simplified Intel 8254 Timer
Implementation
Objective
The objective of this lab is to design, implement, and verify a simplified
version of the Intel 8254 Programmable Interval Timer in Verilog. The im-
plementation will focus exclusively on Mode 0 (Interrupt on Terminal Count)
operation of the timer.
Introduction
The Intel 8254 is a programmable interval timer/counter designed for microprocessor-
based systems. It contains three independent counters, each capable of oper-
ating in one of 6 different modes. In this lab, you will implement a simplified
version with the following characteristics:
• Support for Mode 0 (Interrupt on Terminal Count) only
• Three 8-bit counters (instead of 16-bit)
• Data bus buffer, control register, and read/write logic
• Write-only operation: Only writing to registers and counters
is implemented. Reading is not supported.

Mode 0 Operation
In Mode 0 (Interrupt on Terminal Count), the operation is as follows:
• After the Control Word is written, OUT is initially low.
• OUT remains low until the counter reaches zero by being decremented
after each clock cycle.
• When counter reaches zero, OUT goes high and remains high until a
new count or new Control Word is written.
• GATE = 1 enables counting, GATE = 0 disables counting.

Module Descriptions
1. Data Bus Buffer
Handles data flow between the external data bus and internal modules. In
this simplified implementation, only the write path is implemented (no read
functionality).
Inputs: data in[7:0]
Outputs: data out[7:0]
2. Read/Write Logic
Decodes address inputs and generates write enable signals for counters and
control register. Only write operations are handled.
Inputs: cs, wr, a1, a0
Outputs: ctr0 wr, ctr1 wr, ctr2 wr, ctrl reg wr
3. Control Register
Stores the control word for each counter. All three control words are
stored and continuously provided to their respective counters via
wires.
Inputs: clk, wr en, data in[7:0]
Outputs: ctr0 control[7:0], ctr1 control[7:0], ctr2 control[7:0]
4. Counter
Implements Mode 0 countdown with terminal count detection.
Inputs: clk, gate, ctr wr, data in[7:0], control word[7:0]
Outputs: out
5. Top Module (To be completed by students)
The Top Module connects all submodules together to create a complete 8254
timer.

Important Note
In this simplified implementation, only write operations to the registers
and counters are implemented. Reading is not supported. All three
control words are stored in the control register and provided to the
counters via wires, with no control word write strobes.
